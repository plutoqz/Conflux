### 5.2 R1 检索消融（ranx 指标，NDCG@10）

**底座选择（zh-zh）**：

| Embedding | 最佳 ndcg@10 | 备注 |
|---|---|---|
| `text-embedding-v4` | **1.000**（全档） | 基准标杆胜出 |
| `qwen3-embedding-8b` | 1.000（全档） | 与 v4 并列但 4096 维开销大 |
| `jina-embeddings-v4` | 0.963 | 接近 |
| `bge-m3` | 0.963 | 1024/256 档仅 0.819 |

**跨语言（zh-en，中文 query → 英文文档）**：

| Embedding | ndcg@10 | 结论 |
|---|---|---|
| `text-embedding-v4` | **0.819** | 跨语言最强 |
| `jina-embeddings-v4` | 0.815 | 接近 |
| `qwen3-embedding-8b` | 0.806 | **8B 未兑现优势** |
| `bge-m3` | 0.682 | 混合检索垫底 |

**rerank（3 数据集 × 4 方法）**：12 组合 **10 降、1 平、1 微升**（en-en jina +0.013）→ **rerank 不推荐默认**。

**最终配置建议**：`text-embedding-v4` + chunk `512/128` + hybrid top_k=60，**不启用 rerank**。
